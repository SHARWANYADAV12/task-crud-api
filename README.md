# Task API

A simple CRUD API for managing a to-do list using Node.js, Express, and SQLite.

## Features

- Create tasks
- Read all tasks
- Read a task by ID
- Update tasks
- Delete tasks
- Input validation
- Proper HTTP status codes
- SQLite database persistence
- Parameterized SQL queries
- Swagger UI documentation

## Tech Stack

- Node.js
- Express.js
- SQLite
- better-sqlite3
- Swagger UI
- OpenAPI 3.0
- Git & GitHub

## Installation

```bash
npm install
```
